## Version Control - Git Commands

1. Initialise a local git repository
```bash
git init
```

2. Create a new branch
```bash
git checkout -b feature/assessment-answers
```

3. Commit coding scripts
```bash
# add changes
git add .

# commit
git commit -m <commit message>
```


4. Push to public Github repo
```bash
git push
```
